## 下载与安装

- **推荐：QuotaBar-macOS-universal.dmg**，打开后把 QuotaBar 拖入 Applications。
- 也可下载 **QuotaBar-macOS-universal.zip**，解压后将 QuotaBar.app 移到应用程序。
- macOS 14 或更高版本，Intel 与 Apple Silicon 通用；无需安装 Xcode 或自行编译。
- 当前版本采用临时签名，尚未进行 Apple 公证。首次联网下载后，macOS 可能要求在「系统设置 → 隐私与安全性 → 仍要打开」确认来源。
- 启动后保持 QuotaBar 在菜单栏运行。右键桌面 → 编辑小组件 → 搜索 QuotaBar 即可添加原生组件。
