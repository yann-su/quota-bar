## 下载与安装

- 推荐下载 **QuotaBar-macOS-universal.dmg**，打开后把 QuotaBar 拖入 Applications。
- 也可下载 **QuotaBar-macOS-universal.zip**；macOS 14 或更高版本，Intel 与 Apple Silicon 通用。
- 当前采用临时签名，尚未进行 Apple 公证。首次联网下载后，可能需要在「系统设置 → 隐私与安全性 → 仍要打开」确认来源。
- 保持菜单栏应用运行，再从桌面「编辑小组件」添加 QuotaBar。

## 修复反复索要钥匙串密码

- Claude 授权成功后在当前运行期间复用内存凭据，自动刷新不再每次重新请求读取密码。
- 后台读取禁止授权弹窗；遇到需要授权的情况暂停自动读取，等待手动点击「连接 Claude」。取消后不会自动再次发起授权，普通刷新也不会弹授权框。
- 适配 Claude Code 既有的 macOS 文件钥匙串；读取后恢复原交互状态，不修改访问权限，不保存凭据副本。
- 服务端拒绝旧登录后最多静默重读一次；暂停 Claude 时清除内存凭据。
- 重启或更新后若需要重新授权，仍须手动连接。此版本不要求新增开发者证书。
- 83 项测试通过，包括并发刷新只读取一次、拒绝旧凭据、取消授权后暂停，以及静默读取策略恢复。

附件 SHA256SUMS.txt 可校验安装包完整性。
